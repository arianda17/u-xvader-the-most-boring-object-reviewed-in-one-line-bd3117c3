# The Most Boring Object, Reviewed in One Line

`A rubber band: born in a drawer, lives stretched to its limit, dies with a snap, and you never find it again.`

Run it with `node main.ts` — the program prints the single entry line to stdout.

The joke is that a rubber band's entire working life is spent stretched to its limit, only to end with a snap and vanish. Everyone knows that drawer: you reach for it when something needs holding together, and it's already brittle, half-used, and one pull away from snapping back at you.
